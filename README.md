## Why Avira?

Most financial and life-management apps send your data to the cloud, sell your information to advertisers, and charge you for the privilege. **Avira is different.**

- **Your data never leaves your machine.** All AI processing happens locally.
- **No cloud dependency.** Works offline. No subscriptions to third-party APIs.
- **One app for everything.** Finance, health, school, shopping, travel, documents — all in one place.
- **AI that actually helps.** Not a chatbot gimmick — real analysis across 22 financial data sources.

## Privacy & Security

**This is the most important section.** Avira was built from the ground up to keep your data private.

- **100% local AI.** Language models run on your own machine via Ollama. Your prompts, documents, and financial data are never sent to OpenAI, Google, or any cloud service.
- **Automatic PII masking.** Before any text reaches the AI model, Avira's privacy pipeline scans for and masks 18 types of sensitive information — Social Security numbers, credit cards, medical records, bank accounts, and more.
- **No telemetry.** Avira doesn't track what you do, what you search for, or what you trade.
- **No ads.** Ever.
- **Open source.** Inspect the code yourself. MIT licensed.
- **HIPAA-grade document handling.** Medical records are masked with reversible UUIDs so the AI can analyze without seeing your real information.
- **GDPR/CCPA compliant by design.** There's nothing to comply with when you don't collect data.

## Get Started

### Option 1: One-Command Start

```bash
git clone https://github.com/your-org/avira.git
cd avira
./scripts/avira-start.sh
```

Then open **http://localhost:30001** and create your account.

### Option 2: Manual Setup

**Prerequisites:** macOS with [OrbStack](https://orbstack.dev) (or Docker + K8s), [Ollama](https://ollama.com), Node.js 18+, Python 3.11+

```bash
# 1. Pull AI models
ollama pull qwen2.5:14b
ollama pull mistral:7b-instruct
ollama pull nomic-embed-text

# 2. Deploy backend + frontend to Kubernetes
./scripts/avira-start.sh

# 3. Open the app
open http://localhost:30001
```

## FAQ

**Q: Do I need a powerful computer?**
A: A Mac with Apple Silicon (M1 or later) with 16GB RAM is recommended. The AI models run locally and benefit from the Neural Engine.

**Q: Does Avira give real investment advice?**
A: No. Avira is an educational and research tool. It provides data, analysis, and AI-generated insights, but nothing it displays constitutes investment advice. Paper trading uses simulated money only. Always consult a licensed financial advisor.

**Q: Can I use real money to trade?**
A: The paper trading engine uses a $100,000 virtual portfolio. Real trade execution is available on the Enterprise plan through broker integrations (Alpaca, Robinhood) — but you must connect your own brokerage account.

**Q: What happens if Ollama is not running?**
A: The app continues to work for all non-AI features (trading scanner, price data, calendar, etc.). AI-powered features (chat, document analysis, market synthesis) require Ollama to be running.

**Q: Is my medical data safe?**
A: Yes. Medical documents are processed through the privacy pipeline, which masks all protected health information (PHI) before the AI sees it. The original data stays in a local encrypted vault.

**Q: Can my family use it too?**
A: The Enterprise plan supports up to 5 users with shared calendars and task management.
